# Evidencias para justificar este TFM

En este documento se registran las evidencias sólidas que justifican la necesidad del trabajo.

## Descripción de los campos

- _Capa_: Se definen 3 capas en las que podría ayudar este trabajo.
  - _L1 Necesidad_: Es un problema que existe y está documentado
  - _L2 Hueco_: Las soluciones actuales solo cubren una parte
  - _L3 Aportación_: Aportaciones nuevas
- _Fuente_: Referencia a la fuente original
- _Hallazgo_: Mención sobre la información relevante encontrada
- _Valor_: En qué beneficia a este TFM
