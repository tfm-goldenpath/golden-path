## 1. Protocolo de búsqueda

**Preguntas de investigación para guiar la búsqueda** (_RQ_ `Research Question`)

- **RQ-A** ¿Qué vectores de ataque existen para la cadena de suministro Software, qué controles están documentados, qué categorías existen? (Estado del arte y set de pruebas)
- **RQ-B** ¿Qué herramientas existen para la firma de artefactos software y qué motivación tienen?
- **RQ-C** ¿Qué requisitos o regulaciones específicos regulan la entrega de software en el sector asegurador?
- **RQ-D** ¿Existen trabajos previos (tesis, artículos,industria) que resuelvan este problema? ¿Qué valor diferencial puedo aportar?

**Fuentes**: IEEE Xplore + ACM DL, arXiv, Google Scholar, EUR-Lex, EIOPA, publicaciones oficiales SLSA/CNCF/OpenSSF/NIST, repositorios de TFM (RUIdeRA o similares de otras comunidades)

**Criterios de inclusión**: Documentos revisados, de organismos oficiales; Se priorizarán los documentos más recientes en caso de existir múltiples versiones. **Exclusiones**: Marketing de fabricantes, foros, blogs (solo como contexto, nunca como cita estructural), documentos sin citas. **Regla de parada**: La línea de búsqueda se para cuando dos consultas consecutivas no aportan ningún resultado relevante nuevo.

**Herramientas**: Las fuentes conservadas se almacenarán con la herramienta Zotero, que registra automáticamente cada ítem.
